You can now add your own commands to Folio with a short Lua script.

## Download

| | Folio | Folio Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon and Intel) | `Folio-2.0.1-macos-universal.zip` | `Folio-Lite-2.0.1-macos-universal.zip` |
| **Windows** (64-bit) | `Folio-2.0.1-windows-x64.zip` | `Folio-Lite-2.0.1-windows-x64.zip` |
| **Linux** (x86-64) | `folio-2.0.1-linux-x64.tar.gz` | `folio-lite-2.0.1-linux-x64.tar.gz` |

New to Folio? The [user guide](https://github.com/solacecasino/folio#readme) takes about ten minutes to read.

## init.lua

Put an `init.lua` in Folio's config folder (**Folio → Open Config Folder**):

```lua
folio.register_command("date", function()
  folio.insert_text(os.date("%Y-%m-%d"))
end)
```

Then bind the command in `keys.toml`:

```toml
"cmd+shift+d" = "lua date"
```

- **When it runs:** Folio runs `init.lua` when it starts, again whenever you save the file, and on **Reload Config** (`Cmd+Shift+R`). You never need to restart.
- **What scripts can do:** `folio.get_text`, `folio.set_text`, `folio.get_cursor`, `folio.set_cursor`, `folio.insert_text` and `folio.register_command`. [docs/customizing.md](https://github.com/solacecasino/folio/blob/main/docs/customizing.md#initlua) explains each one.
- **Undo:** each command is one step.
- **Errors:** `print` output and every error, with its line number, go to **Help → Log** (`Cmd+Alt+L`). A broken script never stops Folio.
- **Safety:** scripts can't read or write your files, run programs or use the network. They get Lua's string, table, math, utf8 and coroutine libraries and the clock, nothing more. A command that runs longer than a second is stopped, and scripts share 32 MB of memory.
- **Cost:** without an `init.lua`, Lua never starts, and Folio uses the same memory as 2.0.0. With the example above, it was 43 MB on a Retina Mac.

## Compatibility

Nothing changed for existing setups. Documents, themes, settings, `keys.toml`, adapters and plugins work exactly as in 2.0.0. `lua <name>` is a new command name, so no existing binding can mean something different.
