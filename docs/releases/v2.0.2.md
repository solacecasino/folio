A small patch: Folio settles down faster after it starts, scripts can work with the selection, and bug reports now include how much memory Folio is using.

## Download

| | Folio | Folio Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon and Intel) | `Folio-2.0.2-macos-universal.zip` | `Folio-Lite-2.0.2-macos-universal.zip` |
| **Windows** (64-bit) | `Folio-2.0.2-windows-x64.zip` | `Folio-Lite-2.0.2-windows-x64.zip` |
| **Linux** (x86-64) | `folio-2.0.2-linux-x64.tar.gz` | `folio-lite-2.0.2-linux-x64.tar.gz` |

New to Folio? The [user guide](https://github.com/solacecasino/folio#readme) takes about ten minutes to read.

## What changed

- **Animations are paced to your screen.** When something on screen fades in, Folio now draws at most one frame per screen refresh, which is 60 times a second on most displays. Since 2.0.0 it had drawn as fast as the processor allowed. Startup was the most visible case: about 370 frames in the first 8 seconds, now about 40. Typing still shows immediately.
- **Memory in bug reports.** **Help → Log → Copy Debug Info**, and **Help → Report a Problem**, now include Folio's memory use and the most it has used so far, along with the window's size, screen scale and zoom. The memory figure matches what the system's monitor shows: Activity Monitor on macOS, Task Manager on Windows, and the resident size on Linux. This is how we'll finally get real Windows and Linux numbers, so please include it when you report something.
- **Lua: the selection.** `folio.get_selection()` returns the selection's start, end and text. `folio.set_selection(from, to)` selects a range. A command that wraps the selected text in quotes is now three lines; [docs/customizing.md](https://github.com/solacecasino/folio/blob/main/docs/customizing.md#initlua) has the example.
- **Lua errors appear once in the Log**, not twice. An error in `init.lua` now also shows in the status line when the file reloads, not only in the Log.

On a Retina Mac, memory after opening is unchanged at 38–39 MB.

## Compatibility

Nothing existing changed. The four Lua functions from 2.0.1 work exactly as before, and `get_selection` and `set_selection` are new names. Documents, themes, settings, `keys.toml`, adapters and plugins are untouched.
