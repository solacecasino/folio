Adapters are now easy to find, add and share.

## Download

| | File |
|---|---|
| **macOS** (Apple Silicon) | `Folio-0.7.0-macos-arm64.zip`. Unzip, drag to Applications, right-click → **Open** the first time. |
| **Windows** (64-bit) | `Folio-0.7.0-windows-x64.zip`. Unzip and run **folio.exe**. |
| **Linux** (x86-64) | `folio-0.7.0-linux-x64.tar.gz`. Unpack and run `./install.sh`. |

## Find adapters

**[The adapter catalog](https://github.com/solacecasino/folio-adapters/blob/main/CATALOG.md)** lists every adapter, with a direct download for your computer. It updates itself from each adapter's latest release. **Browse Adapters** in Folio opens it.

## Add them

- **Drop an adapter's zip on the Folio window.** That's the whole install. Dropping a `.folio` document opens it.
- Downloaded the wrong one? Folio says so and names the zip to get instead, such as `-windows-x64.zip`.
- Each adapter in **Folio → Adapters…** links to its homepage.

## Make and share your own

1. **[Use the template](https://github.com/solacecasino/folio-adapter-template/generate):** a working Python adapter in about 15 lines, thanks to a one-file helper, `folio.py`.
2. **Push a version tag.** The template publishes a release for you, with a zip per platform if your adapter is compiled.
3. **[List it](https://github.com/solacecasino/folio-adapters/issues/new?template=list-my-adapter.yml)** by typing your repo's name into a form.

Adding an adapter from a folder while you work on it now skips `.git`, `target/` and `dist/`.
