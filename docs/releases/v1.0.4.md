Small fixes for people trying Folio, and a user guide.

## Download

| | Folio | Folio Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon and Intel) | `Folio-1.0.4-macos-universal.zip` | `Folio-Lite-1.0.4-macos-universal.zip` |
| **Windows** (64-bit) | `Folio-1.0.4-windows-x64.zip` | `Folio-Lite-1.0.4-windows-x64.zip` |
| **Linux** (x86-64) | `folio-1.0.4-linux-x64.tar.gz` | `folio-lite-1.0.4-linux-x64.tar.gz` |

New to Folio? The [user guide](https://github.com/solacecasino/folio#readme) covers everything in about ten minutes.

## New

- **Intel Macs.** The Mac download is now one app that runs on both Apple Silicon and Intel.
- **A Help menu:**
  - **User Guide** opens the guide in your browser.
  - **Report a Problem…** copies Folio's debug info and opens the problem form, so you only have to paste.
  - **Keyboard Shortcuts** and **Log** moved here from View.

## Fixed

- **Crashes leave details.** If Folio crashes, it saves what went wrong. The next time it opens, it says so, and Report a Problem includes the details.
- **Your user name stays private.** Debug info writes your home folder as `~`, so file paths in a public report don't show your name.
- **Linux:** Folio's questions (save before closing, allow an add-on) work without zenity, using KDE's `kdialog` or the basic `xmessage`. File pickers already used your desktop's own dialogs.

## Known limits

- Color emoji show as boxes, on screen and in PDFs.
- Not code-signed yet, so each OS warns the first time.
