## Memory

Measured on a MacBook (2560×1664 Retina screen) with the sample document, zooming in 8 steps, out 12 and in 4, as Activity Monitor counts it:

| | Folio 1.0.5 | Folio 1.0.6 |
|---|---|---|
| After opening | 67–75 MB | 67–71 MB (unchanged) |
| Right after zooming | 325 MB | 154 MB |
| A minute later | 261 MB | 87 MB |

Folio keeps every letter it has drawn, at every size, in one texture so text draws quickly. It used to be as wide as the graphics card allows (16,384 pixels on a Mac) and never shrank. Now it's at most 2,048 pixels wide (16 MB at the very most), and once you stop zooming it starts over with only the sizes on screen.

Some of the memory right after zooming is memory Folio has already freed; macOS takes it back on its own over the following minute.

Tried and dropped, because they made no measurable difference: handing freed memory back to macOS by hand, a different memory allocator (mimalloc), removing egui's built-in emoji fonts (they're read straight from the app file), and a plain title bar.

Windows and Linux aren't measured yet.

## Known limits

- Color emoji show as boxes, on screen and in PDFs.
- Not code-signed yet, so each OS warns the first time.
