**Folio 1.0.** A document editor that ships bare and is customizable through plain text files, now with sandboxed plugins, on macOS, Windows and Linux.

## Download

| | Folio | Folio Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon) | `Folio-1.0.0-macos-arm64.zip` | `Folio-Lite-1.0.0-macos-arm64.zip` |
| **Windows** (64-bit) | `Folio-1.0.0-windows-x64.zip` | `Folio-Lite-1.0.0-windows-x64.zip` |
| **Linux** (x86-64) | `folio-1.0.0-linux-x64.tar.gz` | `folio-lite-1.0.0-linux-x64.tar.gz` |

**macOS:** unzip, drag Folio.app to Applications, then right-click → **Open** the first time (it isn't notarized). **Windows:** unzip and run `folio.exe`; if SmartScreen appears, **More info → Run anyway**. **Linux:** unpack and run `./install.sh`, or just `./folio`.

## New in 1.0

- **Plugins.** WebAssembly extensions (WASI Preview 2) that run inside Folio in a sandbox. A plugin gets nothing (no files, no network, not even your document) unless its `plugin.toml` asks, and every plugin runs under time, memory and output limits. A plugin that crashes is restarted; one that keeps failing is turned off. Put plugins in `plugins/` in the config folder; their commands appear in a new **Plugins** menu and can be bound in `keys.toml` (`plugin "Name" command`). See [docs/plugins.md](https://github.com/solacecasino/folio/blob/main/docs/plugins.md).
- **Folio Lite.** Every platform also gets a smaller edition without the plugin runtime. Adapters work in both.
- **Smaller builds** overall from whole-program optimization.
- **Plugins vs. adapters:** plugins are the main way to extend Folio. [Adapters](https://github.com/solacecasino/folio-adapters/blob/main/CATALOG.md) (separate programs) stay for external tools and background work, like PDF Export and Folio Link.

## Everything else Folio does

Real pages with headers and footers; paragraph styles and themes as TOML files; every shortcut remappable in `keys.toml`; a formatting language for the status line, title, headers and panels; panels you arrange; find and replace; spell check with your system's dictionaries; smart quotes and dashes; autosave, crash recovery and version history; `.folio` files are readable JSON.

## Known limits

- Not code-signed yet, so each OS warns the first time you open Folio.
- macOS builds are Apple Silicon only; Windows and Linux builds are x86-64.
- No lists, images, tables or links in documents yet.
