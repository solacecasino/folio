Folio uses about half the memory it did.

## Memory

Measured on a MacBook (2560×1664 Retina screen) with the sample document open, as Activity Monitor counts it:

| | Before | After |
|---|---|---|
| Folio 1.0.4 → 1.0.5 | 128 MB | 61–80 MB |
| An empty window drawn the same way, for comparison | | 69 MB |

What changed:

- **The app icon** was a 1024×1024 image that macOS kept a 32 MB copy of for the Dock. It's 256×256 now.
- **Only the current theme's fonts are loaded**, not every theme's, and they're read straight from disk instead of copied into memory.
- **An unused system-font loader** in Folio's toolkit is turned off.
- **At most two screen buffers** instead of three.

What's left is mostly not Folio's: the window's screen buffers (about 14 MB each at this window size, more on a bigger window or screen) and macOS's graphics libraries. An empty window made with the same toolkit uses about as much, so this is close to the floor without replacing how Folio draws. The number moves between runs because macOS sometimes keeps a third screen buffer.

Not measured yet: Windows and Linux, which count graphics memory differently. Plugins add their own memory on top, only when you install them.

## Known limits

- Color emoji show as boxes, on screen and in PDFs.
- Not code-signed yet, so each OS warns the first time.
