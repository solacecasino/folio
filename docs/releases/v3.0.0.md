Folio is now **text9000**, the writing app of the 9000 series, next to [splice9000](https://github.com/solacecasino/splice9000) (video), [wave9000](https://github.com/solacecasino/wave9000) (sound) and [grace9000](https://github.com/solacecasino/grace9000) (photos). It's the same app, renamed, and it now works with its sister apps directly. Nothing you had stops working.

## Working with the 9000 series

- **Open or drop** a video, a sound file or a photo, or a `.splice`, `.wave` or `.grace` project, and it opens in splice9000, wave9000 or grace9000 instead.
- **Link to a file.** **Format → Link to a File…** links the selection (or the file's name) to any file. `Cmd`-click the link and the file opens in its 9000 app, so a script or shot list can point at the edit, the takes and the stills. Links to files beside the document are written relative to it, so the whole folder can move together.
- **The 9000 menu** opens any sister app that's installed, and only those. `app splice9000` in `keys.toml` binds one to a key.
- **The series look.** The window's top strip, menus, Adapters window, Log and other small windows now use the series' graphite with text9000's own signal color, ink green. There's a new icon and wordmark in the same style as its sisters. Your documents keep their own themes.

text9000 finds the sister apps by itself: on macOS anywhere they're installed, on Linux through their app-menu entries or your `PATH`, and on Windows on your `PATH` or unzipped next to text9000's folder. Otherwise, name their paths under `[apps]` in `settings.toml`.

## Coming from Folio

- **Your setup comes along.** On its first start, text9000 copies Folio's whole config folder into its own: settings, keys, themes, `init.lua`, adapters, versions and recovery files. Folio's folder isn't touched, so Folio 2 still works if you keep it.
- **New documents are `.t9k`.** `.folio` documents open as before and save back as `.folio`. The format inside is the same.
- **`folio://` links still work**, including Folio Link invites, and so does the new `text9000://`.
- **`init.lua`:** the Lua table is now `text9000`. `folio` is the same table, so existing scripts run unchanged.
- **Adapters and plugins** written for Folio work unchanged. Adapters receive the version under both `folio` and `text9000`.
- **`FOLIO_CONFIG_DIR`**, `FOLIO_FRAME_TIMES` and `FOLIO_LOG_FILE` still work. `TEXT9000_…` is the new spelling.
- **On Linux,** `install.sh` replaces Folio's app-menu entry and leaves a `folio` shortcut to text9000 in `~/.local/bin`, so scripts that run `folio` keep working.

What changes for you:

- The name, the icon and the window colors.
- The config folder's name.
- The macOS app's identity (`app.text9000.editor`). macOS asks once before opening it, and you may need to choose text9000 again for documents you'd set to "Always Open With" Folio.
- The Linux window class (`text9000`), which matters if you have window-manager rules for Folio.
- The GitHub address. The old one redirects to the new one.

## Not tested yet

- The sister apps don't send files back to text9000 yet. That's planned for their next releases.
