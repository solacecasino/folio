Folio now runs on **macOS, Windows and Linux**.

## Download

| | File | Then |
|---|---|---|
| **macOS** (Apple Silicon) | `Folio-0.6.0-macos-arm64.zip` | Unzip, drag **Folio.app** to Applications. First time: right-click → **Open** (it isn't notarized yet). |
| **Windows** (64-bit) | `Folio-0.6.0-windows-x64.zip` | Unzip anywhere and run **folio.exe**, keeping the `themes` folder next to it. If SmartScreen appears: **More info → Run anyway**. |
| **Linux** (x86-64) | `folio-0.6.0-linux-x64.tar.gz` | `tar xzf folio-0.6.0-linux-x64.tar.gz && cd folio-0.6.0-linux-x64 && ./install.sh`, then find Folio in your app menu. Or just run `./folio`. |

Adapters (PDF export, Folio Link, Writing Tools) are separate, and now come for all three platforms too: [folio-adapters v0.2.0](https://github.com/solacecasino/folio-adapters/releases/tag/v0.2.0).

## What's new

- **Windows and Linux.** The same app, same files, same themes. The menus sit at the top of the window in your theme's colors, and every `Cmd` shortcut is `Ctrl`. Your `keys.toml` works unchanged on every computer: `cmd` means Ctrl there.
- **Spell check everywhere.** macOS and Windows use the system's own spell checker and dictionaries. Linux uses Hunspell dictionaries (install e.g. `hunspell-en-us`, or drop `.aff`/`.dic` files into `dictionaries/` in the config folder).
- **Themes that travel.** A theme font can now be a list, such as `["Georgia.ttf", "georgia.ttf", "DejaVuSerif.ttf"]`, and the first one the computer has wins. Bare file names are found in the system's font folders. The built-in themes use this, so they look right on all three platforms.
- **Config folder per platform:** `~/Library/Application Support/Folio` (macOS), `%APPDATA%\Folio` (Windows), `~/.config/folio` (Linux). Set `FOLIO_CONFIG_DIR` for a portable setup.
- **Adapters on every platform.** Zips are unpacked by Folio itself. Removed adapters go to the Trash or Recycle Bin. `./program` in `adapter.toml` finds `program.exe` on Windows, and `python3` falls back to the `py` launcher.

## Known limits

- macOS builds are Apple Silicon only. Windows and Linux builds are x86-64.
- Not code-signed yet, so each OS warns the first time you open it.
- On Linux, dialogs use the desktop portal, or `zenity` if there's no portal.
