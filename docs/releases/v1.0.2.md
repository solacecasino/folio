## New

- **Lists and links.** Folio now draws, edits and prints bulleted and numbered lists (nested up to 8 levels, numbered 1. / a. / i. by default) and links. To make them, add the optional **Rich Content** adapter from the [catalog](https://github.com/solacecasino/folio-adapters/blob/main/CATALOG.md): it adds Bulleted List (Cmd+Shift+8), Numbered List (Cmd+Shift+7), Add Link… (Cmd+K) and Remove Link to the Format menu. Without it Folio stays bare, but documents with lists and links still look right.
- **Tab** indents: it inserts a tab, or in a list moves the item one level in (Shift+Tab: out, and out of the list at the top). Enter continues a list; Enter on an empty item, or Backspace at its start, ends it.
- **Cmd-click (Ctrl-click) a link** to open it. Only web and mail links open, so a shared document can't start programs.
- Themes can style lists (`[lists]`: indent, bullets, number styles) and links (`colors.link`).
- With [PDF Export 0.2.2](https://github.com/solacecasino/folio-adapters/releases), links in PDFs are clickable. With Folio Link 0.3.1, lists and links stay in sync when editing together.
- Adapters: protocol 5 adds `doc.set_list`, `doc.set_link`, the selection in `doc.get`, and `ui.prompt` for asking a question.

## Known limits

- Images and tables are next.
- Characters a theme's font doesn't have (like arrows in Georgia) show as boxes in exported PDFs.
- Not code-signed yet, so each OS warns the first time.
