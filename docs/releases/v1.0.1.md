Fixes and polish for Folio 1.0.

## Download

| | Folio | Folio Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon) | `Folio-1.0.1-macos-arm64.zip` | `Folio-Lite-1.0.1-macos-arm64.zip` |
| **Windows** (64-bit) | `Folio-1.0.1-windows-x64.zip` | `Folio-Lite-1.0.1-windows-x64.zip` |
| **Linux** (x86-64) | `folio-1.0.1-linux-x64.tar.gz` | `folio-lite-1.0.1-linux-x64.tar.gz` |

## New

- **Folio Link invites are links.** Click a `folio://join#…` invite and Folio opens and joins the session. Needs [Folio Link 0.3](https://github.com/solacecasino/folio-adapters/releases).
- **Double-click `.folio` files** to open them: on macOS (including when Folio isn't running yet), on Windows (Folio sets this up when it starts), and on Linux (`install.sh` sets it up).
- **File → Open Recent**, and Folio remembers its window's size and place.
- **View → Log** (Cmd+Alt+L): everything adapters and plugins print, plus errors, so you can build add-ons without a terminal.
- **Plugins (preview):** they can now replace a range of text, show text in the status line, and fill panels. Drop a plugin's zip on the window to install it. Start your own from [folio-plugin-template](https://github.com/solacecasino/folio-plugin-template).
- **About** shows the edition (Folio or Folio Lite) and where the config folder is.

## Fixes

- Folio Link's Share and Join didn't work on Windows and Linux (copying the invite used a macOS-only tool). Fixed in Folio Link 0.3.

## Known limits

- Not code-signed yet, so each OS warns the first time.
- Plugins are a preview: their interface may still change.
