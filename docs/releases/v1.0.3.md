Fixes, many of them found by running Folio on Windows and Linux machines and looking at the screen.

## Download

| | Folio | Folio Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon) | `Folio-1.0.3-macos-arm64.zip` | `Folio-Lite-1.0.3-macos-arm64.zip` |
| **Windows** (64-bit) | `Folio-1.0.3-windows-x64.zip` | `Folio-Lite-1.0.3-windows-x64.zip` |
| **Linux** (x86-64) | `folio-1.0.3-linux-x64.tar.gz` | `folio-lite-1.0.3-linux-x64.tar.gz` |

## Fixed

- **Copy and paste keep formatting.** Bold, italic, styles, lists and links survive copying within Folio, and between Folio windows. Other apps still get plain text.
- **Arrows, check marks and other symbols** show on screen and print in PDFs, using the system's symbol fonts when the theme's font lacks them (PDF Export 0.2.2 or later).
- **Windows and Linux:**
  - Tab no longer also selects the Folio menu (where the next space opened it).
  - Typing a space or Enter could move the caret to wherever the mouse was. Fixed.
  - Ctrl+Left/Right and Ctrl+Backspace/Delete work by word, and Ctrl+Home/End go to the start and end of the document, as on other Windows and Linux apps.
  - Menu titles stay readable while open.
- **Linux:** if `libxkbcommon-x11` is missing, Folio says what to install instead of crashing, and warns at startup when `zenity` (needed for its questions) is missing. `install.sh` checks both.
- **Small screens:** on first launch the window fits the screen instead of running off the bottom.
- **Windows:** `folio --version` prints in a terminal.

## New, for reporting problems

- **View → Log → Copy Debug Info** copies Folio's version, your system, installed add-ons and recent errors (never document text) to paste into a report.
- **[Report a problem](https://github.com/solacecasino/folio/issues/new?template=bug.yml)** and **[Suggest something](https://github.com/solacecasino/folio/issues/new?template=idea.yml)** forms on GitHub.

## Known limits

- Color emoji show as boxes, on screen and in PDFs.
- Not code-signed yet, so each OS warns the first time.
