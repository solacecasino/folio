A small patch: no more half-drawn frames on a Mac.

## Download

| | text9000 | text9000 Lite (no plugins) |
|---|---|---|
| **macOS** (Apple Silicon and Intel) | `text9000-3.0.2-macos-universal.zip` | `text9000-lite-3.0.2-macos-universal.zip` |
| **Windows** (64-bit) | `text9000-3.0.2-windows-x64.zip` | `text9000-lite-3.0.2-windows-x64.zip` |
| **Linux** (x86-64) | `text9000-3.0.2-linux-x64.tar.gz` | `text9000-lite-3.0.2-linux-x64.tar.gz` |

## Fixed

- **A frame could flash half drawn on macOS**, most likely while typing or scrolling quickly. The window drew into a screen buffer macOS could still be showing, so when frames came faster than the screen shows them, a half-drawn frame could flash up. It now takes turns between three buffers and only draws into one macOS is done with. The fix is in [core9000 0.1.3](https://github.com/solacecasino/core9000/releases/tag/v0.1.3), the 9000 series' shared core; grace9000 0.0.4 has it too.

## Compatibility

Everything from 3.0.1 works the same. Nothing else changed.
