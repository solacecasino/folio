Folio 2.0 replaces how Folio draws its window. The graphics card is no longer used: the processor draws only the parts of the window that changed. On a Mac, Folio now uses about half the memory it did in 1.0.6. Nothing was removed: your documents, themes, settings, shortcuts, adapters and plugins work as before.

## Memory

Measured on a MacBook with a 2560×1664 Retina screen, using the sample document. The figures are what Activity Monitor shows, over three runs:

| | Folio 1.0.6 | Folio 2.0 |
|---|---|---|
| After opening | 67–71 MB | 38 MB |
| Right after zooming (in 8 steps, out 12, in 4) | 154 MB | 44–47 MB |
| 30 seconds later | 87 MB | 44–45 MB |
| With the Adapters window also open | | 45–50 MB |

Under 1.x, an empty window drawn with the graphics card already used 69 MB on this Mac. Folio 2.0 opens below that with a document in it.

## What changed

- **The processor draws the window.** Folio no longer loads the graphics card's driver or keeps two or three full-window copies of the screen for it.
- **Only what changed is redrawn.** Typing a letter redraws that line and the caret, which takes well under a millisecond. Redrawing the whole window, for example after zooming or scrolling, takes 7–11 ms on this Mac.
- **The window has one screen buffer.** On macOS, Folio draws straight into the image the system displays. Windows and Linux use one buffer, or two on Wayland.
- **Memory that Folio frees goes back to the system right away.** Before, macOS held on to it, which is why memory stayed high for a while after zooming.
- **Downloads are smaller**, because the graphics libraries are gone: the macOS download went from 18.1 to 15.5 MB, Windows from 10.6 to 8.4 MB and Linux from 12.2 to 10.6 MB. Folio Lite went from 10 to 7.1 MB on macOS, 5.8 to 3.5 MB on Windows and 7.6 to 5.9 MB on Linux.
- **Idle means idle.** When nothing changes, Folio only wakes to blink the caret and to check for edited settings files.

Everything else works as before: menus, the Adapters window (still its own window), find and replace, spell checking, PDF export through adapters, dropping files, screen readers, typing in other languages, and the clipboard.

## For people building Folio

- eframe and wgpu are replaced by `winit`, `egui-winit`, and a small drawing layer of Folio's own in `src/shell`. [ARCHITECTURE.md](https://github.com/solacecasino/folio/blob/main/ARCHITECTURE.md#drawing) explains how it works.
- `FOLIO_FRAME_TIMES=1` prints how much of the window each frame redrew and how long it took.
- Building on Linux no longer needs OpenGL development files.
- On Linux, Folio's window now reports itself as `folio` instead of `Folio`, which matches its `folio.desktop` file.

## Known limits

- Memory on Windows and Linux hasn't been measured yet. CI machines have no real screen, so their numbers wouldn't mean much.
- Color emoji show as boxes, both on screen and in PDFs.
- Folio isn't code-signed yet, so each system shows a warning the first time you open it.
